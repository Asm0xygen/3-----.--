# Изменение: QR-коды генерируются по запросу

## ✅ Что изменилось

### ❌ До (автоматическая генерация)

```javascript
// При импорте Excel
POST /api/import/os
→ Автоматически генерировались QR-коды для ВСЕХ активов
→ qrCode сохранялся в базе сразу
```

### ✅ После (генерация по запросу)

```javascript
// 1. Импорт Excel БЕЗ генерации QR
POST /api/import/os
→ Активы создаются с qrCode: null

// 2. Пользователь выбирает активы в UI
// (чекбоксы, множественный выбор)

// 3. Генерация QR для выбранных позиций
POST /api/import/generate-qr
Body: { "assetIds": ["id1", "id2", "id3"] }
→ QR генерируются только для выбранных активов
```

## 🔧 Технические изменения

### backend/src/routes/import.ts

**Изменено:**

- ❌ Убрана автоматическая генерация QR в `/api/import/os`
- ✅ Активы создаются с `qrCode: null`
- ✅ Добавлен endpoint `POST /api/import/generate-qr`

**Новый endpoint:**

```typescript
POST /api/import/generate-qr

Request:
{
  "assetIds": ["asset_id_1", "asset_id_2"]
}

Response:
{
  "success": true,
  "generated": 2,
  "errors": [],
  "assets": [/* активы с QR-кодами */]
}
```

## 🎯 Workflow пользователя

1. **Загрузка реестра ОС** → Активы импортируются БЕЗ QR
2. **Просмотр списка активов** → Пользователь видит все активы
3. **Выбор позиций** → Чекбоксы для выбора нужных активов
4. **Генерация QR** → Кнопка "Сгенерировать QR для выбранных"
5. **QR готовы** → Печать/инвентаризация
