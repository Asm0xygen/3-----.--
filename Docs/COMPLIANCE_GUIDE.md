## Обзор требований

### 152-ФЗ «О персональных данных»

Основные требования:

- **Согласие субъекта ПД** (ст. 9) — обработка ПД возможна только с согласия
- **Хранение на территории РФ** (ст. 18, ч. 5) — запись, систематизация, накопление ПД граждан РФ — на серверах в РФ
- **Права субъектов ПД** (ст. 14) — доступ, исправление, удаление, отзыв согласия
- **Меры защиты** (ст. 19) — организационные и технические меры защиты
- **Уведомление РКН** (ст. 22) — регистрация в Реестре операторов ПД

### РКН (Роскомнадзор)

Дополнительные требования:

- **Блокировка контента** (149-ФЗ, ст. 15.1) — удаление запрещённого контента в течение 24 часов
- **Уведомление об инцидентах** — в течение 72 часов
- **Предоставление информации** по запросам РКН

## Реализованные меры

### ✅ 1. Согласие на обработку ПД

**Где:** `backend/src/routes/auth.ts` (POST /register)

- Регистрация **невозможна без согласия** (поле `consent: true`)
- Дата согласия сохраняется в `User.consentDate`
- Отзыв согласия: POST /api/gdpr/revoke-consent

### ✅ 2. Хранение данных на территории РФ

**Production:**

- БД PostgreSQL/Supabase должна быть размещена в дата-центре на территории РФ
- Указать фактический ДЦ в `RKN_COMPLIANCE.md`

**Mock mode (dev):**

- Данные хранятся в памяти локально

### ✅ 3. Права субъектов ПД

**API:** `/api/gdpr`

| Право | Endpoint | Описание |
|-------|----------|----------|
| Доступ к данным | GET /my-data | Получить информацию о своих ПД (ст. 14) |
| Экспорт | GET /export | Экспорт в JSON (портируемость) |
| Уточнение | POST /data-request | Запрос на изменение/удаление |
| Отзыв согласия | POST /revoke-consent | Отзыв согласия (ст. 9) |
| Удаление | DELETE /delete-account | Полное удаление аккаунта и ПД |

### ✅ 4. Меры защиты

**Организационные:**

- Политика обработки ПД (PRIVACY_POLICY.md)
- Пользовательское соглашение (TERMS_OF_SERVICE.md)
- Политика комплаенса РКН (RKN_COMPLIANCE.md)

**Технические:**

- **Шифрование паролей:** bcrypt (10 раундов)
- **JWT-токены:** с ограниченным сроком (7 дней)
- **HTTPS:** обязательно в production
- **Аудит:** логирование всех действий (AuditLog)
- **Валидация:** входных данных
- **CORS:** явное указание домена в production

### ✅ 5. Аудит и логирование

**Таблица:** `AuditLog`

Логируются:

- Регистрация, вход, выход
- Доступ к данным, экспорт
- Отзыв согласия, удаление аккаунта
- IP-адрес, User-Agent, timestamp

**Просмотр логов:**

```sql
SELECT * FROM audit_logs WHERE userId = 'xxx' ORDER BY timestamp DESC;
```

### ✅ 6. Запросы субъектов ПД

**Таблица:** `DataRequest`

Типы запросов:

- `access` — доступ к данным
- `correction` — исправление данных
- `deletion` — удаление данных
- `consent_withdrawal` — отзыв согласия

**Обработка:**

- Автоматическая (для access, export, deletion)
- Ручная (для correction) — через админ-панель

## API для субъектов ПД

### Аутентификация

Все запросы требуют JWT-токен:

```
Authorization: Bearer <token>
```

### 1. Получить информацию о своих ПД

**Запрос:**

```http
GET /api/gdpr/my-data
Authorization: Bearer <token>
```

**Ответ:**

```json
{
  "personalData": {
    "id": "xxx",
    "email": "user@example.com",
    "name": "Иван Иванов",
    "consent": true,
    "consentDate": "2026-06-07T12:00:00Z",
    "lastLogin": "2026-06-07T12:30:00Z",
    "createdAt": "2026-06-01T10:00:00Z"
  },
  "dataProcessing": {
    "purposes": ["Регистрация и аутентификация", "..."],
    "legalBasis": "Согласие субъекта ПД (ст. 6 152-ФЗ)",
    "retentionPeriod": "До удаления аккаунта или отзыва согласия"
  }
}
```

### 2. Экспорт данных

**Запрос:**

```http
GET /api/gdpr/export
Authorization: Bearer <token>
```

**Ответ:**

```json
{
  "user": { ... },
  "exportDate": "2026-06-07T12:00:00Z",
  "format": "JSON"
}
```

### 3. Запрос на изменение/удаление

**Запрос:**

```http
POST /api/gdpr/data-request
Authorization: Bearer <token>
Content-Type: application/json

{
  "requestType": "correction",
  "reason": "Нужно исправить имя"
}
```

**Типы запросов:**

- `access` — доступ к данным
- `correction` — исправление данных
- `deletion` — удаление данных
- `consent_withdrawal` — отзыв согласия

### 4. Отзыв согласия

**Запрос:**

```http
POST /api/gdpr/revoke-consent
Authorization: Bearer <token>
Content-Type: application/json

{
  "reason": "Больше не хочу использовать сервис"
}
```

**Последствия:**

- Согласие отменяется (User.consent = false)
- Создаётся запрос на удаление (DataRequest)
- Данные удаляются в течение 30 дней

### 5. Удаление аккаунта

**Запрос:**

```http
DELETE /api/gdpr/delete-account
Authorization: Bearer <token>
Content-Type: application/json

{
  "password": "user_password"
}
```

**Важно:**

- Требуется подтверждение паролем
- Аккаунт и все ПД удаляются немедленно
- Отменить действие невозможно

## Процедуры и регламенты

### Обработка запросов субъектов ПД

1. **Автоматическая обработка** (access, export, deletion):
   - Выполняется немедленно через API
   - Логируется в AuditLog

2. **Ручная обработка** (correction):
   - Запрос сохраняется в DataRequest
   - Ответственный рассматривает в течение 10 рабочих дней
   - Обновляет status: in_progress → completed/rejected
   - Направляет ответ на email

### Реагирование на инциденты

**При утечке или компрометации ПД:**

1. **В течение 24 часов:**
   - Зафиксировать инцидент
   - Провести первичную оценку
   - Принять меры по локализации

2. **В течение 72 часов:**
   - Уведомить РКН ([форма](https://rkn.gov.ru))
   - Уведомить затронутых субъектов ПД (email)

3. **В течение 30 дней:**
   - Провести расследование
   - Устранить причины
   - Представить отчёт РКН

### Удаление данных

**При отзыве согласия или удалении аккаунта:**

1. Пометить запись как deleted (soft delete)
2. Удалить ПД из активной БД
3. Удалить резервные копии с ПД
4. Очистить логи с ПД (старше 1 года)
5. Составить акт уничтожения ПД
6. Уведомить субъекта о выполнении

## FAQ

### Нужно ли регистрироваться в РКН?

**Да**, если обрабатываете ПД граждан РФ. Исключения (ст. 22 152-ФЗ):

- Обработка для личных/семейных нужд
- Обработка только ФИО без других данных

### Где хранить данные?

На серверах, расположенных **на территории РФ**. Трансграничная передача запрещена без специального разрешения.

Рекомендуемые провайдеры:

- **Selectel** — Санкт-Петербург, Москва
- **VK Cloud** — Москва
- **Yandex Cloud** — Москва, Владимир
- **МТС Cloud** — Москва

### Как получить согласие?

При регистрации:

1. Чекбокс «Я согласен с [Пользовательским соглашением] (#) и [Политикой обработки ПД] (#)»
2. Поле `consent: true` в API
3. Сохранить дату согласия (`consentDate`)

### Сколько хранить данные?

- **Активные аккаунты:** до удаления или отзыва согласия
- **После удаления:** удаляются в течение 30 дней
- **Архивные копии:** до 3 лет (зашифрованные)
- **Логи:** до 1 года

### Можно ли передавать данные третьим лицам?

**Нет**, кроме случаев:

- Субъект дал явное согласие
- Передача необходима для исполнения договора
- Передача предусмотрена законом (запрос уполномоченных органов)

### Что делать при запросе от РКН?

1. Проверить подлинность запроса
2. Предоставить информацию в установленный срок (обычно 10 дней)
3. Зафиксировать в AuditLog

### Штрафы за нарушения

**Административные (ст. 13.11 КоАП РФ):**

- Обработка без согласия: 75 000 – 150 000 руб. (юр. лица)
- Нарушение хранения: 150 000 – 300 000 руб.
- Нарушение защиты: 300 000 – 500 000 руб.

**Уголовные:**

- Ст. 137 УК РФ: до 200 000 руб. или лишение свободы до 2 лет
- Ст. 272 УК РФ: до 500 000 руб. или лишение свободы до 5 лет
