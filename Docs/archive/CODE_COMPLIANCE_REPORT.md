## 5. Ключевые расхождения

### 5.1 Мультитенантность (КРИТИЧНО)
**Требуется** (PROJECT_STATUS.md, л. 322-324):
> SaaS. Логическая изоляция организаций.

**Факт**: Нет Organization; все ОС показываются всем пользователям.

### 5.2 Помещения и ОС (КРИТИЧНО)
**Требуется** (л. 38, 148-152):
> Учет имущества по помещениям. Каждое ОС закрепляется за помещением.

**Факт**: Нет Room; Asset.roomId отсутствует.

### 5.3 Инвентарные номера
**Требуется**: Инвентарный номер уникален **в рамках организации**.

**Факт**: `@unique` глобально — нарушение концепции.

### 5.4 Статусы ОС
**Требуется** (л. 169-176): 6 enum-значений.

**Факт**: `String` без валидации.

### 5.5 DaData интеграция
**Требуется** (л. 108-114):
> По ИНН через DaData автоматически заполняются реквизиты организации.

**Факт**: DaData не вызывается; Organization не создаётся.
