# Общая концепция проекта

3авхоз.рф — российский SaaS-сервис для оперативного учета, инвентаризации и контроля размещения основных средств организации.

Сервис предназначен для заведующего хозяйством (завхоза), специалиста АХЧ или руководителя организации.

Проект **не заменяет бухгалтерскую систему (1С и аналогичные)** и не ведет бухгалтерский учет.

Источником данных об основных средствах является бухгалтерская система.

3авхоз.рф использует выгрузку из бухгалтерии как основу и предоставляет удобный инструмент для:

- учета имущества;
- размещения по помещениям;
- инвентаризации;
- диагностики;
- подготовки документов;
- аналитики.

---

# Цели MVP

Реализовать минимально достаточный SaaS-продукт для коммерческого запуска.

В MVP должны быть реализованы:

- регистрация организации;
- импорт имущества из бухгалтерии;
- учет имущества по помещениям;
- перемещение имущества;
- проведение инвентаризации;
- диагностика;
- подготовка документов;
- мобильная инвентаризация;
- биллинг;
- административная панель.

Проект сознательно ограничен одним пользователем на организацию.

Роли пользователей отсутствуют.

---

# Основные бизнес-принципы

## Источник данных

Источником данных является бухгалтерская система.

Поддерживаются выгрузки:

- XLS
- XLSX
- CSV
- TXT

После импорта файл не хранится.

При необходимости пользователь повторно получает выгрузку из бухгалтерии.

---

## Область ответственности сервиса

Сервис отвечает за:

- размещение имущества;
- поиск имущества;
- инвентаризацию;
- диагностику;
- подготовку документов;
- контроль состояния имущества.

Сервис не отвечает за:

- бухгалтерский учет;
- амортизацию;
- изменение стоимости;
- постановку на баланс;
- бухгалтерское списание.

---

## Пользовательская модель

В MVP:

- одна организация;
- один пользователь;
- без ролей;
- без разграничения прав доступа.

# Основные функциональные модули

## Регистрация

Регистрация выполняется по:

- Email
- Пароль
- ИНН

По ИНН через DaData автоматически заполняются реквизиты организации.

---

## Организация

Карточка организации содержит:

- реквизиты;
- контакты;
- договорные реквизиты;
- банковские реквизиты.

---

## Комиссии

Поддерживаются:

- инвентаризационная комиссия;
- комиссия по списанию.

Для комиссии хранится:

- номер приказа;
- дата;
- наименование;
- текст приказа;
- состав комиссии.

Комиссии используются при генерации документов.

---

## Помещения

Реестр помещений организации.

Каждое ОС закрепляется за помещением.

---

## Основные средства

Карточка ОС содержит:

- наименование;
- инвентарный номер;
- серийный номер;
- стоимость;
- дату постановки на учет;
- срок полезного использования;
- помещение;
- статус.

Статусы:

- В эксплуатации
- На хранении
- На диагностике
- В ремонте
- К списанию
- Списано

Стоимость изменяется только в бухгалтерской системе.

---

## Импорт

Поддерживаемые форматы:

- XLS
- XLSX
- CSV
- TXT

Этапы:

1. загрузка;
2. анализ;
3. сопоставление колонок;
4. предварительный просмотр;
5. импорт.

---

## QR / Штрихкоды

Для каждого ОС генерируются:

- QR;
- Code128.

Поддерживается массовая печать.

---

## Перемещение

Фиксируется история:

- дата;
- помещение-источник;
- помещение назначения;
- комментарий.

---

## Диагностика

Используется для подготовки имущества:

- к ремонту;
- к списанию.

---

## Инвентаризация

Поддерживаются два режима.

### Полная

Проверяется всё имущество организации.

### По помещениям

Проверяются выбранные помещения.

Для каждого объекта фиксируется:

- найден;
- отсутствует;
- находится не в своем помещении.

---

## Печатные документы

Предусмотрены:

- книга учета;
- ведомость помещения;
- инвентаризационная ведомость;
- ведомость диагностики;
- ведомость списания;
- акт списания.

Комиссии автоматически подставляются.

---

## Мобильное приложение

Функции:

- авторизация;
- поиск имущества;
- сканирование QR;
- сканирование Code128;
- инвентаризация;
- перемещение;
- просмотр карточки ОС.

---

## Биллинг

Поддерживаются тарифные планы.

Оплата:

Для организаций:

- счет;
- СБП;
- банковская карта.

Для физических лиц:

- СБП;
- Мир;
- Visa (при доступности);
- Mastercard (при доступности).

После окончания подписки:

режим "Только просмотр".

---

Разделы:

- общий дашборд;
- организации;
- биллинг;
- технические рассылки;
